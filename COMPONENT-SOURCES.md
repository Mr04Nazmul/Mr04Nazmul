## Source snapshots and permissions

Original source and license snapshots are in `sources/upstream/`. Skiper source explicitly allows personal/commercial use and modification with attribution for the free version; visible footer link retained. Magic UI and Serenity MIT notices and React Bits MIT + Commons Clause are preserved in `THIRD-PARTY-NOTICES.md` and snapshot files. Third-party permissions are not replaced by this repository's attribution draft.

Manrope is self-hosted under the SIL Open Font License. Lucide icons are supplied by the installed package. Halal Checker screenshot was captured from the owner's live public website. NAZORIX and Receipt AI captures render the owner's original repository HTML locally because their legacy website URLs redirect/return 404; NAZU logo comes from the owner's nazulabs repository. Abstract milestone illustrations are original CSS and Lucide icons, not claimed as screenshots.
