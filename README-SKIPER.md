# DevNazu React portfolio

React 19 + Vite + TypeScript + Tailwind 4 + Motion + Lenis + Embla + Lucide.

- `npm ci`
- `npm run dev` (use `-- --host 127.0.0.1` in restricted containers)
- `npm run build` — TypeScript and production build
- `npx playwright install --with-deps chromium`
- `npm test` — production preview + desktop/iPhone/Android browser and accessibility checks

`COMPONENT-SOURCES.md` maps every section to its source and adaptations. `THIRD-PARTY-NOTICES.md` preserves notices. `public/CNAME` retains devnazu.jp. GitHub Actions validates staging and deploys main only after QA passes. Existing README profile content is preserved.
